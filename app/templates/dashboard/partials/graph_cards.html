Why don't these numbers add up?

×

Example: Site Down showed +128 at the top of a weekday's popup, but its duration rows underneath added up to +189. Here's why.

Top green (+128)

= 559 − 431 → (all tickets last week) − (all tickets Week 37).

Bottom green numbers add up to +189

= 481 − 292 → (fixed-only tickets last week) − (fixed-only tickets Week 37).

So the top +128 and the bottom +189 aren't even built from the same two numbers:

  • Top uses "all tickets" both weeks.
  • Bottom uses "only the fixed ones" both weeks.

In short

The category's own row counts every incident that started that day. The duration rows only count the ones that have since been fixed — an incident still open has no duration to show yet. That's expected, not a mistake.
