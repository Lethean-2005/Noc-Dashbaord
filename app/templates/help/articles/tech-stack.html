Technology Stack

Backend

  • Flask web framework, Jinja2 templates.
  • SQLAlchemy + psycopg2 for PostgreSQL, pymssql for MSSQL.
  • SQLite (WAL mode) local cache, Waitress production server.

Frontend

  • Leaflet for map rendering, Tabler Icons throughout.
  • Vanilla JavaScript — no frontend framework.

Export & Alerting

  • openpyxl for spreadsheet export, Pillow for alert table images.
  • Telegram Bot API and Teams incoming webhooks, both plain HTTP.

See the Feature Report PDF under Downloads for the full architecture behind this stack.
