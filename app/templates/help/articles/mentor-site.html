Mentor Site

Flags specific sites for focused monitoring, independent of their normal status.

  • Use Download template to get a blank CSV with the right site_code column header, then use Import File to bulk-add sites from it.
  • Use Input Site Codes to add one or more sites by typing their codes directly — space-separated to add several at once.
  • Use View Alarms to open the alarm drilldown scoped to only the configured mentor sites.
  • Monitors the same alarm types as the Dashboard's other cards: Site Down, Main AC Failure, Low/High DC Voltage, DG-On, RECT Failure, Door Alarm, and Other.
