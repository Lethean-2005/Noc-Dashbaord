Dashboard

Each card's badge shows a live count. Click any badge to open its drilldown table.

  • IP Ezecom combines ISP POP badges (POP DOWN, POP POWER) with Ezecom's own alarm badges in one card; IP Telcotech/Cellcard is the same idea for TCT — both are MSSQL-sourced, alongside VVIP Site and Mentor Site.
  • RAN Status has four independent badge groups side by side — Site Down, Main AC Alarm, DC Low/High, and Tech Down — each with its own View button and a Hub-Site/Diamond/Gold/Silver/Bronze grade breakdown.
  • Incident / INC-WO by Status shows Incident and INC-WO badge groups side by side, each with its own View button.
  • Three chart cards summarize trend data: Incident Age, Incidents Closed, and Incident Volume. Every bar, dot, or segment on them is clickable the same way a badge is, and hovering shows an exact-value tooltip first.
  • The Incidents Closed and Incident Volume drilldowns support a Filter by Category checkbox control — only categories actually present in that table are listed. Checking more than one category shows rows matching any of them, and the export respects the same selection.
  • Incident Age – Open's own count still opens the usual drilldown table, but each bar also has its own worklog icon (, next to the count) — click it to see every currently-open incident in that age bucket, each one expandable to its own real worklog history (comments and status/field changes pulled straight from the source system) without leaving the dashboard.

Badge colors

GreenCount is 0 — healthy
RedCount is above 0 — needs attention

This zero/nonzero rule describes alarm-count badges, including the ISP POP badges inside IP Ezecom and the alarm-count badges in IP Telcotech/Cellcard. Incident and WO status badges can use separate colors to identify their workflow states; their color alone is not a zero/nonzero health result.
