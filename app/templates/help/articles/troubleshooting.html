Troubleshooting

For questions about a specific card's logic, data source, or an unexpected count, check the relevant drilldown's date filter and export first. Most apparent discrepancies trace back to a sync-timing window (every background job refreshes every few minutes, not instantly) rather than a data error.

Still stuck? The Query & Data Reference PDF under Downloads explains exactly which query and cache table feeds each card, and the Virtual Machine Setup Guide covers dependency and startup issues.
