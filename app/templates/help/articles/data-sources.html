Where the Data Comes From

Every page reads from a local cache — never live from MSSQL or PostgreSQL directly — so pages load instantly and the two source databases only ever see a small, steady stream of background sync queries.

  • MSSQL is the source for ISP POP / EZE / TCT / IT NODE alarms, On-Air site master data, POP data, VIP/VVIP sites, and Partner Contact.
  • PostgreSQL (Streamline) is the source for Incidents, INC-WOs, the broader alarm feed, and Planned/Other site master data.
  • On-Air site status comes from MSSQL specifically because it reflects real network inventory more directly and updates sooner than Streamline's own status field — the two sources are kept independent rather than merged, so if they ever disagree about a site, the Map shows both instead of silently picking one.
  • Full technical detail — every query, every cache table, and the Cambodia Province/District/Commune/Village hierarchy — is in the Query & Data Reference PDF under Downloads.
